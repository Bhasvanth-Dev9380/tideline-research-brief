Research brief · September 2026

Everyone sells a company brain. Nobody has measured one.

Sixty-plus companies now market shared memory for AI agents. On the one public benchmark that tests whether a memory stays correct when facts change, every practical-cost system scores 3% and 1%. On the one public benchmark that measures what a session actually costs, the most-starred token optimizer makes sessions 53% more expensive. The leading open-source memory layer wrote this week that role-based permissions are something "most memory layers don't [have] yet."

This brief is the 25-day plan to change that. Not a product sprint: the mathematical models and the protocol first, each one measured on a public harness with a cost column, before a single feature is built on top. What comes out is Tideline v2's foundation and the only set of reproducible numbers in the category.

The moment

The claims are loud. The measurements are missing.

The phrase "company brain" hardened into a category in 2026. We scanned all four Y Combinator 2026 batches — 660 companies — and found five selling exactly that (Hyper, Memory Store, Savant, Alloovium, Glen) and seven selling only token reduction. Outside YC the money is larger: Engram raised $98M for a parametric memory layer, Highlight $40M, Jedify $24M, Twin1 $20M. Ninety-one products in total, from primary sources.

Every one of them makes the same four claims: shared memory across people and agents, permission-aware, correct over time, cheaper. Only the first is table stakes. The other three have almost no public evidence behind them. Glen's "29% fewer tokens" is one vendor-run replay on one repository, no data published; its shipped CLI injects no memory per prompt — the agent has to call a search tool. Sentra's benchmark scores appear only on Sentra's own site, which itself says to treat them as "vendor-reported until independent replication."

Meanwhile the independent numbers point the other way. A 2,908-run study found that cutting tool tokens by 38.4% raised the bill by 6.8%, because cache traffic is most of the spend. Enterprise vendors enforce permissions at read time on documents and none of them labels derived artifacts — the summaries, pages and audit traces where the leaks actually happen.

Thesis

Not a new algorithm. A protocol, three models, and numbers nobody has.

We checked. The core mechanism a company brain needs — propagate a change through every fact that depends on it — was published three times this year: MemoRepair named "the cascade update problem" in May, MemTX built transactional belief commit with cascading repair in July, and Lemmalog shipped a bi-temporal Datalog memory in August. The label lattice for who-may-read-what is Denning 1976 and Microsoft's Fides. The salted cache prefix is a vLLM RFC. Anyone claiming to have invented these is wrong, and reviewers know it.

What does not exist is the composition, stated as invariants and tested, and the measurements. So the foundation we build in 25 days is:

  • A protocol — eight invariants over one fact schema, each a property-based test any implementation must pass. The headline theorem is noninterference through the prompt cache: a person outside a compartment cannot learn its contents even by timing the provider's cache.
  • Three mathematical models, each replacing a heuristic that has already failed a measurement: four-valued beliefs for "I don't know any more" (MEME Absence); a source-reliability fixed point replacing "confirmed because it was read three times"; conformal injection with a billed-token budget replacing "inject the top five."
  • Public numbers with a cost column — MEME, the THOL session-cost protocol, and a leak suite — the first reproducible set in the category.

Why math first, features later. Every later line of code is checked against the conformance suite. A store that passes it cannot launder a private fact into company memory, cannot report a stale dependent as current, and cannot leak through the cache — whatever the UI does on top. Get that right and the workspace, the living pages and the admin console are plumbing.


The eight invariants

I1admissionuntrusted sources can't author or supersede protected facts
I2joina derived fact is as restricted as its most restricted source
I3pre-filterrecall is computed only over what the reader may see — count and timing included
I4cacheblocks ordered by label, nonces at boundaries; org memory cached once for everyone
I5closurea superseded fact recomputes or flags every dependent, without an LLM pass over the store
I6erasurepurge removes the provenance closure and emits a receipt
I7audit"could this person have known this at that time" is decidable from the log
I8doorsreaders of a fact grow only through an audited door, signed by every contributor

Tide table · the 25 days

Six phases. Each one builds a piece of Tideline v2 and produces the receipt that it works.

Every phase is a build. The number at the end of it is not a separate activity — it is how we know the thing we just built does what we said. MEME and THOL are not other people's products; they are public exam papers that every memory system sits, which is what makes a score mean anything. Days are calendar days from 2 September.

Phase 0Days 1–3
Instrument

Build: the harness that will grade every later phase.

A four-method adapter that lets any standard memory exam drive the Tideline API, and a billing ledger in the eval harness that records the four token classes a provider actually charges for — fresh input, cache write, cache read, output. Then run today's Tideline through both, untouched, so the rest of the month has a starting line. The third reading is dependency-edge extraction recall: MemoRepair shows 1% of missing edges leaks 17.7%, so this number bounds what Phase 2 can possibly achieve.

Receipt: where Tideline stands today on correctness-under-change, on dollars per solved task, and on edge recall. Nobody in the category has published any of the three, about themselves or anyone else.

Phase 1Days 4–8
Foundation

Build: the protocol, as code that runs.

The fact schema every later phase writes against — value, valid interval, label, provenance, dependencies — plus the label lattice where user, team, project and company memory are one mechanism rather than four stores. Then a reference implementation in a few hundred lines of plain TypeScript, deliberately naive so it is obviously correct, and a conformance suite that generates random organizations, fact graphs and staff changes and checks the eight invariants hold under all of them.

Receipt: the suite runs green against the reference model and red against today's Tideline at exactly the gaps we already found by reading the code. From here, every line written for the rest of the month is checked automatically.

Phase 2Days 9–14
Change

Build: memory that stays correct when a fact changes.

Dependency edges that carry the rule in the words it was written in, and propagation on supersession: when the deploy target changes, the facts that depended on it either recompute or are marked unknown — without a language model pass over the store. Underneath it, four-valued belief cells so "I no longer know" is a value the store computes rather than a sentence the prompt hopes for. This is the mechanism that makes a self-updating company page possible at all.

Receipt: the correctness-under-change exam, three seeds, with the cost column beside it. The only published system that passes it today costs seventy times the baseline and wrecks plain recall doing so.

Phase 3Days 15–18
Trust

Build: confidence that comes from agreement, not from repetition.

Today Tideline promotes a belief after it has been read three times, which means exposure validates truth — a fact becomes trusted by being used. Replace that with a joint estimate over sources and claims: people, tools and channels each carry a reliability that is inferred from where they agree and disagree, and a fact's confidence follows from that. It converges provably, and it composes with the labels because every source already has one.

Receipt: conflict-resolution scores on the public conflict benchmarks, and the old self-reinforcing loop deleted with a measured replacement rather than an opinion.

Phase 4Days 19–23
Cost

Build: the layer that makes memory cheaper instead of more expensive.

Prompt assembly ordered by label, so the company block is byte-identical for every employee and the provider caches it once for the whole organization, while private compartments sit behind a boundary that nobody outside them can probe. Injection under a budget: instead of "send the top five", send the set that provably holds retrieval quality above a bound for the dollars available. Both live in Brigade's assembler, which is the only place in the stack that can actually control cache placement.

Receipt: billed dollars per solved task with and without Tideline under the public session-cost protocol, the cache-read share, a leak rate per channel, and an erasure receipt that verifies. Submitted to the public leaderboard whose next cycle opens 20 September.

Phase 5Days 24–25
Record

Build: the document that makes the work checkable.

The formal model, the four theorems, the conformance suite and every number from Phases 0–4 with the command that reproduces it. The runner and results go to the exam's authors, because a score nobody else can reproduce is marketing — which is precisely the criticism this brief makes of everyone else's numbers.

Receipt: a draft a hostile reader can check line by line, and a foundation the product is built on from day 26 without revisiting any of it.

What this is not. No day in this plan is spent evaluating a competitor's product. The benchmarks are standardized tests with public code and public data; running Tideline through them is how a claim becomes a fact. The alternative is what the field does now — every vendor scores itself on its own test and asks to be believed.

Risks

Written the way an opponent would argue them.

"Your determinism starts after the edge exists."

True. Propagation is exact; extracting the dependency rule is not. MEME shows cheap extractors strip the contingency wording. That is why edge recall is a Phase 0 number and stays in every table — if it is low, the honest result is "closure is bounded by extraction," not a win.

"MemTX already did permissions plus cascade."

Partly. MemTX has no cost column, no MEME run, no cache invariant, no authorization-time audit. We cite it as the closest prior work and put a capability table next to it, the way it did to its rivals.

"Twenty-five days is not enough to matter."

For a product, correct. For the foundation it is: the numbers exist by day 14, the cost result by day 23. What it does not produce is the workspace, the admin console or the Codex and Cursor hooks. Those start on day 26 against a suite that is already green.

"Nobody outside will verify it."

The plan depends on that being false. MEME's harness and data are public; the runner goes to the authors; THOL publishes raw per-run data and accepts arms. If nobody replicates, the brief says "vendor-reported" about our own numbers, the way we say it about Sentra's.
